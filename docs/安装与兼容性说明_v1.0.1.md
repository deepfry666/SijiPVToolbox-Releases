# 四季光伏工具箱 v1.0.1 安装与兼容性说明

- 软件版本：`v1.0.1`
- 程序集版本：`1.0.1.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v1.0.1.exe`
- 前一版本：`v1.0.0`

## 本次变更

修复配重页底部操作按钮在紧凑工具箱宽度下被压缩、右侧按钮被裁切的问题。配重页现在
为 4 个按钮提供完整列定义，并根据识别状态动态分配宽度：识别前隐藏的“重新识别”不再
占位，3 个可见按钮铺满操作栏；识别后 4 个按钮按文字需要重新分配宽度。

`v1.0.1` 保持 `v1.0.0` 的五模块发布边界，仍不包含“混凝土屋面支架大样”。更新页尺寸
修复、导轨和配重业务规则均保持不变。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v1.0.1.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，确认首页显示版本 `1.0.1`。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。当前安装包和五个 DLL 没有
Authenticode 代码签名，Windows 可能显示“未知发布者”。
