# 四季光伏工具箱 v0.4.1 安装与兼容性说明

- 软件版本：`v0.4.1`
- 程序集版本：`0.4.1.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v0.4.1.exe`
- 前一版本：`v0.4.0`

新构建的 `v0.4.1` 不等于当前已经加载。保存图纸并完全关闭 AutoCAD、探索者和
AutoCAD Core Console，完成升级并重新启动 AutoCAD 后才会切换到新版本。

## 本次变更

工具箱新增第五个“检查软件更新”模块。它从安装包内锁定的
`https://download.imfourj.cn/fourj-pv-toolbox/stable.json` 读取稳定版清单，比较版本，
并在用户确认后下载完整安装器。下载完成前会同时核对清单声明的文件大小和 SHA-256。
网络请求和安装包下载都在后台线程执行，不阻塞 AutoCAD 工具箱界面。

更新模块不会覆盖 AutoCAD 已加载的 DLL，也不会静默启动安装。校验通过后，用户仍须
保存图纸、完全退出 AutoCAD 和探索者，再手动运行完整 EXE。`v0.4.0` 本身没有更新
模块，因此升级到 `v0.4.1` 仍需手工安装一次。

正式下载服务在 ICP、DNS 和 HTTPS 部署完成前可能暂不可达。检查失败只影响更新页，
不会影响自动画导轨、自动布置配重和统计功能。

安装器信息页同步精简为主要功能、AutoCAD 检测结论、固定插件目录和同范围升级说明；
详细的注册表与版本识别信息仍写入安装日志。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 双击 `四季光伏工具箱_Setup_v0.4.1.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，首页应显示三个功能入口。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。其他 AutoCAD 年份、AutoCAD LT、
Mac、浩辰和 ZWCAD 不属于本安装包支持范围。安装器不修改 `SECURELOAD` 或
`TRUSTEDPATHS`。

当前安装包和五个 DLL 没有 Authenticode 代码签名，Windows 可能显示“未知发布者”。
这是已接受的临时分发边界；构建回执如实记录 `NotSigned` 状态及 SHA-256。
