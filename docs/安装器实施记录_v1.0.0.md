# 四季光伏工具箱 v1.0.0 安装器实施记录

- 目标版本：`v1.0.0` / 程序集 `1.0.0.0`
- 交付目录：`SijiPVToolbox_v1.0.0_AutoCAD2020`
- 交付文件：`四季光伏工具箱_Setup_v1.0.0.exe`
- 发布分类：`UNSIGNED`
- Authenticode 预期：`NotSigned`

## 实施内容

- 正式构建移除 `StructuralToolbox.SupportDetail.dll`，Bundle 清单移除支架命令，安装器
  的功能说明同步删除支架大样。
- 支架独立项目、构建脚本、测试和历史文档保留，但不参与正式源码指纹、发布文件集和
  安装器验证。
- 主壳取消按模块 `PreferredPaletteSize` 扩张共享 `PaletteSet` 的行为；只在布局版本从
  `5` 迁移到 `6` 时把旧异常尺寸恢复为 `360 x 580`，之后尊重用户手动尺寸。
- 更新页使用填充式表格布局、百分比宽度输入框、自适应说明文字和可滚动状态区。
- 主壳、Contracts、导轨、配重和更新五个程序集，以及 Bundle、首页、About、README
  和安装器统一为 `1.0.0.0`。

## 发布控制

稳定 ProductCode、UpgradeCode、安装范围标识和已接受的旧 ProductCode 沿用前版。
普通安装禁止降级；安装、升级和卸载仍要求 AutoCAD 已关闭。最终 `outputs/` 只保留
当前版本目录，旧发布物移入历史归档目录。
