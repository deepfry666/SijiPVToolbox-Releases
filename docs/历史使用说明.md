# 四季光伏工具箱

`FourJTooLs`面向AutoCAD的光伏结构绘图工具箱。当前发布版本为`v1.0.8`，程序集版本
`1.0.8.0`。首页提供“自动画导轨”“自动布置配重”“图纸文字翻译”和“检查软件更新”。自动画支架
暂不进入主工具箱和正式安装包。导轨尺寸标注
功能已取消；画轨流程只生成导轨，不生成、修改或删除尺寸标注。

开发区已经完成模块化拆分：主工具箱只负责首页、导航、Ribbon 和模块加载；导轨、
配重和在线更新分别由独立 DLL 提供，公共接口放在稳定的 Contracts DLL 中。既有导轨、
配重命令和单 EXE 安装方式不变。`v1.0.8` 交付六个正式 DLL；
`outputs/` 只保留当前安装包，旧版移入 `outputs/archive/`。

`v1.0.7` 是上一发布版本。`v1.0.8` 保持 AutoCAD 2020 R23.1 兼容边界；安装新包后
仍需重新启动 AutoCAD，才能切换到新版本。

本轮恢复翻译完成提交 `4e098b0` 的功能组合；两套导轨标注均已移除，翻译支持直接替换和确认后替换。

## 安装

1. 保存图纸并完全关闭AutoCAD、探索者和AutoCAD Core Console。
2. 双击`outputs/SijiPVToolbox_v1.0.8_AutoCAD2020/四季光伏工具箱_Setup_v1.0.8.exe`。
3. 在兼容页确认AutoCAD 2020 R23.1显示“【结论：可以安装】”；其他候选版本会显示
   “【结论：当前不支持】”。
4. 全新安装默认选择“仅为我安装”；本机已有系统级`v0.3.3`时，选择“为所有用户
   安装”并同意UAC。
5. 安装完成后，先启动或重启AutoCAD，再在命令行输入`JJJJ`。

当前安装包未配置代码签名证书，Windows可能显示“未知发布者”；这是真实签名状态，
不表示安装包已签名。内部构建回执记录EXE、DLL的`NotSigned`状态和SHA-256。
正式安装默认写入：

`%APPDATA%/Autodesk/ApplicationPlugins/ZhStructureToolbox.bundle`

## 命令

| 命令 | 作用 |
|---|---|
| `JJJJ` | 打开“四季光伏工具箱”首页 |
| `STPVRAIL` | 直接运行“自动画导轨” |
| `STPVRAILSTAT` | 手动框选统计导轨总米数并生成表格 |
| `STPVBALLAST` | 打开左侧“自动布置配重”页面 |
| `STPVBALLASTARRAYSETTINGS` | 为特殊组件阵列设置单独的配重参数 |
| `STPVBALLASTARRAYTABLE` | 使用当前识别快照插入独立的组件阵列清单 |
| `STPVBALLASTPIERRECOGNIZE` | 点选确认手画圆墩或方墩，使其及复制件进入配重统计 |
| `STPVBALLASTSTAT` | 框选统计配重，按尺寸分类并生成表格 |
| `STPVARRAYRECOGNIZE` | 独立识别完整组件阵列，支持多次框选和对象去重 |
| `STPVARRAYTABLE` | 插入独立模块识别得到的组件阵列统计表 |
| `STTOOLBAR` | 尝试恢复顶部 Ribbon 页签 |
| `STABOUT` | 显示版本和核心兼容验证范围 |

配重页面先按外轮廓断开净距 `G` 识别完整 `M×N` 组件阵列，界面同屏显示 `G`
示意图和逐规格汇总，并可插入与配重块统计表分开的组件阵列清单。识别支持顶层闭合
二维多段线和块参照、多方向阵列及多次框选去重；组件变化后旧识别结果自动失效。
配重默认按组件阵列自身方向前后对称布置；可按组件排数设置前侧中心边距和
相邻配重中心距，特殊阵列可单独覆盖。配重外轮廓不得越出组件边缘，中心点到组件边缘
的限距默认为 800 mm。配重高度进入统计数据但不参与平面绘图；仅手动框选统计会在图纸中
插入简单统计表。生成结果继续保持一榀一个外层块，统计时逐个读取榀内标准单墩；复制到
模型空间的标准单墩也单独计数。手画圆墩或闭合矩形可先运行
`STPVBALLASTPIERRECOGNIZE` 点选确认，再通过 `STPVBALLASTSTAT` 统一框选统计。
选择“自定义前侧”时，界面会显示与输入栏对应的 `F/S` 俯视示意图；默认对称
模式下隐藏该图。

Ribbon创建失败不会阻断核心命令，仍可使用`JJJJ`或直接命令。

## 自动画导轨

1. 在首页打开“自动画导轨”，设置导轨数量、首末总间距、贯通净距、端伸、图层、
   颜色和多段线全局宽度。
2. 选择一个组件闭合轻量多段线作为图层样本，再框选处理范围。
3. 工具自动按方向、标高和空间连通性分组，导轨始终垂直组件长边。
4. 预览显示未提交事务中的最终导轨：`C`确认、`X`取消。

本工具不生成、修改或删除导轨尺寸标注。需要尺寸时，请直接使用 AutoCAD 原生命令。

默认参数为 2 根导轨、首末总间距 1400 mm、贯通净距 20 mm、两端各伸出
100 mm；导轨图层为“导轨”，ACI 6 洋红色，全局宽度为 0。所有参数均可修改。

## 样式与避让

距屋面边、女儿墙、轴线或底图轮廓的定位尺寸由用户使用 AutoCAD 原生命令完成。
`v1.0.8`不支持
短边布置、块参照/Xref 内组件、弯折/圆弧/3D 导轨，也不支持 AutoCAD LT、Mac、
浩辰或 ZWCAD。
