## 验收要求

- 首页在“自动画导轨”和“自动布置配重”之间显示“导轨对齐标注”，Ribbon 同序显示按钮。
- “开始标注”、Ribbon 按钮和 `STPVRAILDIM` 均进入 `GDBZ V1.0` 流程；预览可确认和取消，
  生成结果可一次 `UNDO` 撤销。
- 内置脚本与用户附件 SHA-256 一致；缓存文件缺失或被改动时自动恢复。
- `%APPDATA%\StructuralToolbox` 中的既有设置在 `v1.0.5 -> v1.0.6` 升级后保留。
- 最终发布目录只含 `四季光伏工具箱_Setup_v1.0.6.exe`。
- Bundle 只含五个正式 DLL，在线更新继续只使用 GitHub Release；已安装 `v1.0.5` 能在
  “检查软件更新”页发现并校验下载 `v1.0.6`。
