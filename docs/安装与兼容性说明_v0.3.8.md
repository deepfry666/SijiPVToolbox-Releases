# 四季光伏工具箱 v0.3.8 安装与兼容性说明

- 软件版本：`v0.3.8`
- 程序集版本：`0.3.8.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v0.3.8.exe`
- 前一版本：`v0.3.7`

新构建的 `v0.3.8` 不等于当前已经加载。保存图纸并完全关闭 AutoCAD、探索者和
AutoCAD Core Console，完成升级，再重新启动 AutoCAD 后才会切换到新版本。

## 功能变更

本版本深化自动布置配重：配重外轮廓不得越出组件阵列边界，`800 mm` 限值按配重
中心点到组件边缘计算。默认仍前后对称；自定义时输入前侧中心边距和相邻配重
中心距，后侧边距由程序计算，参数矛盾则停止生成并提示错误。前后方向以每个组件
阵列自身方向为准，可按组件排数设置默认值，也可对特殊阵列单独覆盖。

配重新增高度数据、统一自定义图层和分尺寸颜色。高度不改变平面图形，但会进入统计；
第一种尺寸沿用图层颜色，其他不同尺寸自动换色，用户也可在界面为每种尺寸指定颜色。

生成配重时可直接生成分尺寸统计表，也可后续框选统计。数量按每个独立配重块计算，
不把一整槀当作一个对象。导轨同样支持生成时和后续框选统计，结果为导轨总米数。
两类统计均支持“仅工具生成对象”和“所有合格对象”，统计结果在图纸中生成简单表格。

自动画导轨仍只生成导轨，不生成、修改或删除尺寸标注；需要尺寸时请使用 AutoCAD
原生命令。本工具箱固定按 `1 图纸单位 = 1 mm` 计算，不提供其他单位配置。

## 安装

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 双击安装 EXE。
3. 兼容性页显示 AutoCAD 2020 R23.1“可以安装”后继续。
4. 安装完成后启动或重启 AutoCAD，输入 `JJJJ`。

默认安装到当前用户的 Autodesk `ApplicationPlugins` 目录；需要替换系统级旧版时，
在安装模式中选择所有用户并同意 UAC。安装器会检查另一个安装范围，避免同一插件
同时存在两份。

## 升级与卸载

安装器会拒绝覆盖来源不明的同名 Bundle、拒绝普通降级，并在写入前备份已有受管
Bundle。安装失败时恢复备份；卸载只删除 ProductCode 和 UpgradeCode 属于本产品的
Bundle。安装、升级和卸载都要求 AutoCAD 已关闭。

Windows“已安装的应用”中可卸载本工具箱。用户参数位于 `%APPDATA%/StructuralToolbox`，
卸载时保留。当前可安装版本放在 `outputs/SijiPVToolbox_v0.3.8_AutoCAD2020/`，
历史安装包移入 `outputs/archive/`。

## 兼容边界

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。其他 AutoCAD 年份、AutoCAD LT、
Mac、浩辰和 ZWCAD 不属于本安装包支持范围。安装器不会修改 `SECURELOAD` 或
`TRUSTEDPATHS`。

当前安装包没有 Authenticode 代码签名，Windows 可能显示“未知发布者”。内部构建
回执如实记录 EXE 和 DLL 的 `NotSigned` 状态及 SHA-256，不宣称已经数字签名。
