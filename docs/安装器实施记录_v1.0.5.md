# 四季光伏工具箱 v1.0.5 安装器实施记录

- 目标版本：`v1.0.5` / 程序集 `1.0.5.0`
- 交付目录：`SijiPVToolbox_v1.0.5_AutoCAD2020`
- 交付文件：`四季光伏工具箱_Setup_v1.0.5.exe`
- 发布分类：`UNSIGNED`
- Authenticode 预期：`NotSigned`

## 实施内容

- 阵列识别核心新增可独立测试的组件轮廓规范化逻辑。
- 轻量 `Polyline` 和旧式 `Polyline2d` 共用 `0.1 mm` 几何闭合容差。
- 轮廓首尾重合或在容差内时去掉重复末点，再执行四边形和矩形校验。
- 缺口大于容差时保留拒绝行为，并报告实际首尾缺口。
- 识别过程只读取对象，不写回 `Closed` 属性或顶点。
- 五个正式程序集、Bundle、首页、About、README 和安装器统一为 `1.0.5.0`。

## 发布控制

稳定 ProductCode、UpgradeCode、安装范围标识和已接受的旧 ProductCode 沿用前版。
普通安装禁止降级；安装、升级和卸载仍要求 AutoCAD 已关闭。在线更新继续只使用
GitHub Release，并保留 HTTPS、文件大小和 SHA-256 校验。
