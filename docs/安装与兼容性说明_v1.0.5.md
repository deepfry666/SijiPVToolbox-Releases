# 四季光伏工具箱 v1.0.5 安装与兼容性说明

- 软件版本：`v1.0.5`
- 程序集版本：`1.0.5.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v1.0.5.exe`
- 前一版本：`v1.0.4`

## 本次变更

组件识别不再只依赖 AutoCAD 多段线的 `Closed` 属性。轻量多段线和旧式二维多段线的
首尾端点相距不超过 `0.1 mm` 时，即使属性显示“未闭合”，仍按几何闭合组件识别。
重复末点会在四边形判断前规范化；明显开口继续拒绝，并在失败原因中报告实际缺口。

这项处理只影响识别，不会修改原图对象的 `Closed` 属性、顶点或其他数据。配重生成、
单墩统计、导轨和在线更新保持 `v1.0.4` 的行为，正式包继续只含五个模块。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v1.0.5.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，确认首页显示版本 `1.0.5`。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。当前安装包和五个 DLL 没有
Authenticode 代码签名，Windows 可能显示“未知发布者”。
