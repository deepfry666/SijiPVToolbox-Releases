# 四季光伏工具箱 v1.0.0 安装与兼容性说明

- 软件版本：`v1.0.0`
- 程序集版本：`1.0.0.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v1.0.0.exe`
- 前一版本：`v0.4.2`

## 本次变更

正式主工具箱暂时移除“混凝土屋面支架大样”（自动画支架）。首页、Bundle 清单和安装包
不再包含该模块及 `STPVSUPPORTDETAIL*` 命令；独立源码与历史资料仍保留，后续重新设计并
完整验收后再决定是否接入。

修复“检查软件更新”页面把共享工具箱整体拉长、返回首页后尺寸不恢复的问题。`v1.0.0`
首次运行会把旧版遗留的异常 Palette 尺寸迁移回紧凑默认值；迁移完成后，首页与任一模块
之间切换都不会自动改变用户已经设置的工具箱外框尺寸。更新说明、地址、按钮和状态区在
现有空间内自适应，状态区支持滚动。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v1.0.0.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，首页应只显示自动画导轨、自动布置配重和
   检查软件更新。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。其他 AutoCAD 年份、AutoCAD LT、
Mac、浩辰和 ZWCAD 不属于本安装包支持范围。当前安装包和五个 DLL 没有 Authenticode
代码签名，Windows 可能显示“未知发布者”。
