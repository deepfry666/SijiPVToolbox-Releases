# 自动画导轨完善与自动标注方案

- 方案版本：`v0.1`
- 软件基线：四季光伏工具箱 `v0.1.8`
- 状态：历史方案，已由 `自动画导轨与导轨标注实现说明_v0.2.0.md` 取代
- 日期：2026-08-25

## 1. 当前完成情况

`v0.1.8` 已完成以下能力：

- 输出图层名称自定义，默认 `导轨`
- 多段线全局宽度自定义
- ACI 索引色和真彩色自定义
- ByLayer 和实体指定颜色
- 预览与最终实体采用相同图层、颜色和宽度
- 首次呼出尺寸校正及固定底部主操作区

自动标注尚未实施，仍属于“自动画导轨”功能内部能力，不增加首页功能页。

## 2. 参考图的标注语义

对用户提供的导轨标注图，暂按以下含义理解：

| 类型 | 示例 | 暂定含义 |
|---|---:|---|
| 导轨端部伸出 | `100` | 组件外边至导轨端点的实际伸出 |
| 组件阵列宽度 | `6904`、`8058` | 连续组件组的实际总宽度 |
| 断开净距 | `300` | 相邻断开导轨端点之间的实际净距 |
| 导轨中心距 | `1400` | 同排首末导轨中心距离 |
| 相邻排定位 | `2151` | 上下相邻组件排的导轨中心距离 |
| 屋面定位 | `1446`、`(1175)`、`(292)` | 导轨或组件至屋面边界/基准线的距离 |

数值反算显示：`6904 = 6 x 1134 + 5 x 20`，`8058 = 7 x 1134 + 6 x 20`，因此它们很可能是组件阵列宽度，而非包含两端伸出的导轨总长。该语义仍需用户确认。

括号尺寸是否表示参考尺寸，以及屋面定位尺寸具体以导轨端点还是组件外边为测量点，也需确认。

## 3. 总体方案

复杂屋面不按整屋外包矩形生成一条贯通尺寸链。采用以下层级：

1. **方向区**：不同组件方向、规格和标高分别处理，建立沿导轨的局部 `u` 轴和垂直导轨的局部 `v` 轴。
2. **阵列岛**：空间上相互独立的组件区域分别标注，远离的碎片不合并。
3. **组件排**：同一排组件沿 `u` 轴排序，按真实贯通阈值形成连续段。
4. **轮廓变化带**：比较相邻组件排的起终点、断口和导轨区间；轮廓相同的连续多排共用一套标注，发生凹口、凸台、错台或断口变化时新增局部标注。

处理原则是“宁可拆成两个局部标注岛，也不跨越凹口或孔洞错误合并”。

## 4. 标注内容

### 4.1 沿导轨方向

每种不同轮廓生成一套链式尺寸，尺寸点依次来自：

- 可选屋面边界或基准线交点
- 导轨端点
- 组件连续组起点和终点
- 相邻断开导轨端点
- 可选另一侧屋面边界或基准线交点

典型结果类似：

`屋面偏距 | 100 | 阵列宽度 | 100 | 断口净距 | 100 | 阵列宽度 | 100 | 屋面偏距`

### 4.2 垂直导轨方向

按导轨中心线生成尺寸链：

- 同排首末导轨中心距，例如 `1400`
- 相邻组件排最近导轨之间的中心距，例如 `2151`
- 可选首末导轨至屋面边界或基准线的定位尺寸

同一方向、相同轮廓和相同定位关系只标最外侧一套，不逐排重复。

## 5. 屋面边界定位

现有命令只读取组件，无法从复杂建筑底图中可靠判断哪条线是控制屋面边界。屋面定位必须作为可选输入：

- `关闭`：只生成组件和导轨内部尺寸
- `选择闭合屋面轮廓`：对明确的闭合多段线进行自动定位
- `点选基准线`：由用户为当前屋面分区指定控制边或轴线

凹口、洞口或多个候选交点无法唯一判断时，该定位尺寸进入待确认状态，不静默采用任意最近线。

## 6. 标注样式与对象

- 生成原生 AutoCAD `AlignedDimension` / `RotatedDimension`
- 默认跟随当前图纸 `DIMSTYLE`
- 探索者中当前使用 `TSSD...` 样式时继承其文字、箭头、单位和比例
- 不创建探索者专有对象，保证原版 AutoCAD 可编辑
- 建议默认图层 `导轨标注`、ACI 3 绿色、ByLayer
- 指定标注样式不存在时明确提示，不静默换用其他样式

## 7. 自动放置与预览

程序对每个标注岛生成上、下、左、右以及不同外移距离的候选标注带，并按以下条件评分：

- 不穿过组件、导轨、屋面孔洞和已有标注
- 尺寸文字不重叠
- 引出线尽量短
- 优先位于阵列外露侧
- 同一标注岛尽量集中在同一侧

简单矩形阵列允许直接确认；复杂屋面默认先预览。预览至少支持：

- 接受本组或全部接受
- 换边
- 整组移动标注位置
- 拆分或合并标注组
- 跳过本组或全部不标
- 取消并清除全部临时预览

无可用空间时依次尝试外移、换侧和拆分；仍冲突则不生成该组，并明确报告需要人工处理的组数。

## 8. 自动标注前必须完善的导轨数据

当前布局结果只有扁平导轨段，无法可靠回答复杂屋面中的“属于哪一排、由哪些组件形成、为什么断开”。实施前需补充：

- `LayoutGroupId`：方向、规格和标高组
- `ArrayIslandId`：空间独立阵列岛
- `BandId`：组件排及相同轮廓带
- `SegmentId`、`RailIndex`：导轨段及导轨序号
- 源组件句柄或稳定摘要
- 实际组件支承区间和实际首尾伸出
- 断开前后间隙及断开原因
- 同一组件排内导轨的配对关系
- 轮廓签名，用于重复去除

导轨 XData 建议保存 `runId / islandId / bandId / segmentId / railIndex / sourceHash`；标注保存 `RAIL_DIM / annotationSetId / kind / referenceIds`。大量源组件关系不全部塞入 XData，可放入扩展字典。

## 9. “自动画导轨”现阶段还需完善

按优先级排序：

1. **安全更新/重画**：只删除或替换本工具对象，人工实体不动；导轨和标注保持同一更新边界。
2. **重复检测改造**：以工具 XData 和准确空间范围为主，避免输出图层中的普通实体阻断命令。
3. **分组容差**：当前方向容差过严，应适应轻微旋转、对齐和标高误差；最终尺寸仍以真实几何实测。
4. **分组预览**：在生成前突出显示阵列岛、断开位置和被忽略组件，并汇总原因。
5. **测试补充**：矩形、L 形、T 形、U 形、阶梯形、凹口、多岛、多朝向以及狭窄标注空间。
6. **后续兼容**：块参照、外部参照和传统多段线不作为首版必做，但需保持扩展边界。

## 10. 建议实施顺序

1. 补齐分组、来源、连续段和 XData 元数据，画图结果暂不改变。
2. 完成安全更新、重复检测和容差改造。
3. 只生成标注规划和临时预览，用复杂屋面案例验证分区、去重和放置。
4. 创建原生尺寸实体，并与导轨放入同一事务和一次 `UNDO`。
5. 增加可选屋面轮廓/基准线定位。
6. 完成原版 AutoCAD 2020 和探索者环境的安装及回归验证。

## 11. 待用户确认

1. 图中各数值含义是否与第 2 节一致，尤其 `6904/8058`、`300` 和括号尺寸。
2. 是否接受“相同轮廓只标最外侧一套，轮廓变化处增标”。
3. 是否接受复杂屋面自动拆成多套局部尺寸链，不做全屋面强行贯通。
4. 屋面定位是否采用“选择闭合轮廓或点选基准线”，以及是否纳入第一版。
5. 是否使用原生 AutoCAD 尺寸并跟随当前 TSSD/DIMSTYLE。
6. 是否采用默认标注图层 `导轨标注`、ACI 3、ByLayer。
7. 复杂屋面是否默认“预览后确认”，简单阵列允许直接确认。

以上项目确认前，不实施自动标注代码。
