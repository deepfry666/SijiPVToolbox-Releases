# 混凝土屋面支架大样独立模块 v0.1.0

## 实施范围

本模块依据项目根目录的 `支架大样示意图.dwg` 建立，首版保持独立，
不接入自动画导轨和自动布置配重模块。原始 DWG 未被覆盖；固定详图通过
`work/` 内分析副本提取。

可变主图支持：

- 任意倾角；
- 任意组件数量和组件净缝；
- 默认居中、中心距 1400 的夹持位置，或每块组件手动夹持位置；
- 默认 `P=N+1` 或自定义墩子数量；
- 自动墩中心距或全部墩中心线位置；
- 基准立柱高度、支墩外轮廓和高度；
- 斜梁超最外侧三角件中心距离；
- 可选背拉（后拉）、固定节点 A-D 和材料表。

## 几何基准

局部斜向坐标以组件阵列低端为 `s=0`，沿组件斜面向高端为正。
夹持位置 `r` 则以每块组件低端为零点。所有 `r`、`s`、`R`、`S`
均为中心线尺寸，支墩 `D` 或 `Bx×By` 为外轮廓尺寸。

```text
组件阵列斜长 = N × L + (N - 1) × G
自动墩中心 = 组件阵列中心 ± S 的等间距序列
斜梁低端位置 = 最低斜向墩中心位置 - E
斜梁高端位置 = 最高斜向墩中心位置 + E
```

默认单组件采用两墩中心距 `1400 mm`、`E=200 mm`，因此斜梁长度为
`1800 mm`，与源图约 `1805 mm` 的画法一致。组件自身可超出斜梁端部。

`H` 是第一个/最低基准墩位处从支墩顶面到三角件底部的高度；其他立柱
根据倾角和墩位自动变化，以保持斜梁整根、共线。第一版只提示可疑几何，
不把立柱高度限制死。

## 可回读结构

每个主图实体携带：

- 注册应用名 `STPV_SUPPORT_DETAIL`；
- 实例 ID；
- 构件角色，如 `BEAM`、`PANEL_1`、`PIER_1`、`COLUMN_1`；
- 元数据版本。

完整参数以 XML 序列化后分段存入 DWG 命名字典
`STPV_SUPPORT_DETAIL_INSTANCES`。编辑时可选中任意构件，按实例 ID 找到全部
相关实体，在同一事务中删除旧实体并用原基点重建。其他实例和人工图元不处理。

## 固定构件库

`SupportDetailFixedDetails.dwg` 从以下固定区域提取：

- 底座；
- 中压块、边压块；
- 檩条连接件；
- 基础 U 形螺栓；
- 三角件；
- 节点 A-D。

三张 5°、10°、15° 主支架没有进入固定库，避免旧角度几何污染参数化主图。

## 已验证

- 10 项纯几何测试；
- 3 项元数据序列化测试；
- 3 项界面和示意图布局测试；
- AutoCAD 2020 Core Console 真实 DWG 生成、回读、更新；
- 诊断实例由 3 块组件更新为 4 块组件；
- 保存后重新打开仍回读为 4 块组件；
- 重新打开后共 64 个关联实体，其中 25 个主构件为非块参照的原生实体；
- 固定构件库包含 2138 个源图实体。

验证文件均位于 `work/support-detail-*`，未修改根目录源 DWG。
