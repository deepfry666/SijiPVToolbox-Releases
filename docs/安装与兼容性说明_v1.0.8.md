# 四季光伏工具箱 v1.0.8 安装与兼容性说明

- 版本：v1.0.8 / 1.0.8.0；前一版 v1.0.7。
- 支持 AutoCAD 2020 Win64 R23.1，正式负载为六个 DLL，发布分类 UNSIGNED。
- 已移除导轨标注；保留自动画导轨、自动布置配重、统计、图纸文字翻译和更新。
- 翻译以 4e098b0 为完成基线，提供直接替换和确认后替换。首次使用在翻译设置中配置接口和模型；既有配置保留。
- 保存图纸并退出 AutoCAD、探索者和 Core Console，安装四季光伏工具箱_Setup_v1.0.8.exe，选择与旧版相同安装范围。
- 升级后启动 AutoCAD，输入 JJJJ，首页应显示版本 1.0.8 及翻译入口，导轨标注入口已撤下。
- 原图中的既有尺寸不会被软件清理或修改。
- 当前安装器和 DLL 没有 Authenticode 代码签名，Windows 可能显示“未知发布者”。
