# 自动画导轨与导轨标注实现说明

- 文档版本：`v0.2.0`
- 软件版本：四季光伏工具箱 `v0.2.0`
- 状态：已实施并通过 AutoCAD 2020 动态验证
- 日期：2026-08-25

## 已实现

1. 保留原有导轨绘制几何，导轨仍垂直组件长轴。
2. 方向容差由过严的 `0.000001°` 调整为 `0.05°`，能容纳常规 CAD 微小误差，不合并明显不同方向。
3. 布局结果保留方向组、阵列岛、组件排、导轨序号、源组件、真实支承区间、实际伸出和断口元数据。
4. 自动计划端部伸出、组件阵列宽度、断轨净距、同排导轨间距和相邻排导轨间距。
5. 相同轮廓去重；台阶、凹口、凸台和断口变化拆成局部标注链。
6. 使用当前 `DIMSTYLE` 生成原生 `AlignedDimension`，不修改图纸全局标注样式。
7. 支持标注图层、ByLayer/实体颜色、ACI/真彩色和 300/600 等模型显示高度。
8. 最终尺寸块重算后检测文字边界，与现有标注和新尺寸重叠时沿外侧逐级移动。
9. 导轨和尺寸共用阵列岛更新批次，同一事务生成。局部重画不删除框外工具成果，也不删除手工实体。

## 本版边界

- 预览用于确认导轨和尺寸线位；最终文字、箭头和精度由当前 `DIMSTYLE` 生成。
- 预览可全部换边、指定一组换边、跳过全部标注或取消；轮廓分拆和合并由规划器自动完成。
- 无法避让的尺寸不静默提交，而是在事务提交前询问；默认取消并保留旧图。
- 不自动猜测屋面边界，不生成距屋面边或轴线的定位尺寸。
- 不支持短边方案、块参照或外部参照中的组件。
