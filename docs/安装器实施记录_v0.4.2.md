# 四季光伏工具箱 v0.4.2 安装器实施记录

- 目标版本：`v0.4.2` / 程序集 `0.4.2.0`
- 交付目录：`SijiPVToolbox_v0.4.2_AutoCAD2020`
- 交付文件：`四季光伏工具箱_Setup_v0.4.2.exe`
- 发布分类：`UNSIGNED`
- Authenticode 预期：`NotSigned`

## 实施内容

- `StructuralToolbox.SupportDetail` 实现稳定 `IToolboxModule` 契约，主壳通过模块发现生成
  首页入口和页面，不直接依赖支架实现。
- 支架页面提供新建、编辑、查看和删除四项操作，并显示当前保存参数的工程预览。
- 参数窗体继续同屏显示 `N/L/G/α/R/r/s/S/H/E/D/Bx/By/h` 的基准和方向示意图。
- 固定节点详图库作为嵌入资源编入支架 DLL，运行时释放到版本化的用户本地缓存。
- 总构建扩展为主壳、Contracts、导轨、配重、支架大样和更新六个 DLL；所有程序集、
  Bundle 清单、首页、About、README 和安装器同步为 `0.4.2.0`。
- Bundle 清单登记支架新建、编辑、信息和删除命令，安装后无需再次手动 `NETLOAD`。

## 发布控制

稳定 ProductCode、UpgradeCode、安装范围标识和已接受的旧 ProductCode 沿用前版。
普通安装禁止降级；安装、升级和卸载仍要求 AutoCAD 已关闭。最终 `outputs/` 只保留
当前版本目录，旧发布物移入 `work/legacy-output/`。
