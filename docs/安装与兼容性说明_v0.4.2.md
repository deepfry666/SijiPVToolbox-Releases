# 四季光伏工具箱 v0.4.2 安装与兼容性说明

- 软件版本：`v0.4.2`
- 程序集版本：`0.4.2.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v0.4.2.exe`
- 前一版本：`v0.4.1`

新构建的 `v0.4.2` 不等于当前已经加载。请先保存图纸并完全关闭 AutoCAD、探索者和
AutoCAD Core Console，完成安装后重新启动 AutoCAD。

## 本次变更

混凝土屋面支架大样作为第六个独立功能模块接入主工具箱。输入 `JJJJ` 后，首页新增
“混凝土屋面支架大样”，页面提供新建、编辑选中实例、查看实例信息和删除选中实例。
新建和编辑使用带工程示意图的完整参数窗体，支持任意倾角、组件数量和净缝、夹持位置、
墩子数量与位置、支墩尺寸、立柱高度及斜梁端部伸出。

固定节点 A-D 详图库已经嵌入 `StructuralToolbox.SupportDetail.dll`，首次需要固定详图时
释放到当前用户的本地缓存，不要求用户单独管理 DWG 资源文件。支架大样与导轨、配重
结果仍保持数据独立，本版本不自动读取另外两个模块的结果。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v0.4.2.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，首页应显示四个功能入口。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。其他 AutoCAD 年份、AutoCAD LT、
Mac、浩辰和 ZWCAD 不属于本安装包支持范围。当前安装包和六个 DLL 没有 Authenticode
代码签名，Windows 可能显示“未知发布者”。
