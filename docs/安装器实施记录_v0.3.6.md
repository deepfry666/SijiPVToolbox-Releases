# 四季光伏工具箱 v0.3.6 安装器实施记录

- 目标版本：`v0.3.6` / 程序集 `0.3.6.0`
- 交付目录：`SijiPVToolbox_v0.3.6_AutoCAD2020`
- 交付文件：`四季光伏工具箱_Setup_v0.3.6.exe`
- 发布分类：`UNSIGNED`
- Authenticode 预期：`NotSigned`

## 功能变更

v0.3.6 将自动布置配重完整并入左侧工具箱，采用“识别阵列 → 按组件排数设置 →
生成配重”的页面流程。原独立参数窗口退出主流程，识别汇总、跳过原因、生成数量和
红色问题原因改在左侧状态区显示。命令行仅保留组件样本和框选范围的必要图面提示。

圆墩只显示直径，方墩只显示长宽；不同组件排数分别使用一套规则。生成时自动更新
未被人工修改的旧配重榀，人工移动、旋转或缩放的对象继续保护。

## 精简内容

最终 `outputs/` 只保留当前可直接转发的安装 EXE。旧版本安装包移动到
`work/legacy-output/`，不会与当前安装包混淆。构建 inventory、兼容矩阵、安装说明、
验证日志、哈希和回执保留在 `work/`，不重复嵌入安装包。

EXE 只携带 AutoCAD Bundle 必需的 `PackageContents.xml` 和 R23.1
`StructuralToolbox.dll`。安装向导取消欢迎页、签名分类警告页、Ready 摘要页和开始
菜单文档入口，只保留宿主兼容性页以及 Inno Setup 必需的安装进度和完成页。

## 保留的安全控制

- AutoCAD、Core Console 和探索者进程关闭检查；
- AutoCAD 2020 R23.1 注册表、`acad.exe` 和 `acdbmgd.dll` 一致性检查；
- 当前用户/所有用户安装范围冲突检查；
- ProductCode、UpgradeCode 所有权检查；
- 升级、普通降级阻止、安装前备份和失败恢复；
- 卸载前宿主关闭检查，且只删除本产品 Bundle；
- 不修改 `SECURELOAD`、`TRUSTEDPATHS` 和用户工具设置。

签名元数据没有隐藏或伪造：发布定义、构建结果和产物验证仍要求并记录
`Authenticode=NotSigned`。
