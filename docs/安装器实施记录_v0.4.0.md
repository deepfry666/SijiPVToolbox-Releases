## 实施内容

- 新增独立 `BallastPlacementDiagram` 控件，用俯视图表达阵列自身前侧、`F`、`S` 和后侧自动计算值的关系。
- 控件使用稳定高度和响应式横向坐标，适应工具箱宽度和 DPI 缩放。
- 按排数设置页和特殊阵列覆盖窗口共用同一示意控件。
- 仅在自定义前侧模式显示示意图，默认对称模式的布局保持紧凑。
- 根目录 `AGENTS.md` 新增项目级交互规范：凡需输入位置、方向、边距、间距、偏移等自定义工程几何数据，必须在同一界面上下文提供对应示意图。
