# 四季光伏工具箱 v1.0.2 安装与兼容性说明

- 软件版本：`v1.0.2`
- 程序集版本：`1.0.2.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v1.0.2.exe`
- 前一版本：`v1.0.1`

## 本次变更

在线更新页面不再展示内置清单地址、“更新源”输入框和锁定提示；发现新版本后的弹窗也
不再展示清单来源地址。正式 HTTPS 地址仍固定在更新程序集内部，版本检查、完整安装器
下载、文件大小和 SHA-256 校验保持不变。

`v1.0.2` 保持 `v1.0.1` 的五模块发布边界，不包含尚未验收的独立组件构件模块，也不
包含“混凝土屋面支架大样”。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v1.0.2.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，确认首页显示版本 `1.0.2`。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。当前安装包和五个 DLL 没有
Authenticode 代码签名，Windows 可能显示“未知发布者”。
