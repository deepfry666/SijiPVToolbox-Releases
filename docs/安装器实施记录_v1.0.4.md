## 实施内容

- 更新客户端删除 VPS 清单常量，只保留 GitHub Release 的固定稳定清单地址。
- 发行清单的安装包主地址直接指向同版本 GitHub Release，`mirrors` 固定为空。
- 发行准备脚本只生成 GitHub 的安装器、`stable.json`、`sha256.txt`、`release.json` 和
  发布说明，不再生成 `vps/` 站点。
- 发行脚本删除 SSH 和远程目录参数，只负责 tag、GitHub Release 上传、公开和下载回验。
- HTTPS、大小、SHA-256、超时、取消、临时文件和原子下载保护保持不变。
- 五个正式程序集、Bundle、首页、About、README 和安装器统一为 `1.0.4.0`。

## 发布控制

稳定 ProductCode、UpgradeCode、安装范围标识和已接受的旧 ProductCode 沿用前版。
普通安装禁止降级；安装、升级和卸载仍要求 AutoCAD 已关闭。
