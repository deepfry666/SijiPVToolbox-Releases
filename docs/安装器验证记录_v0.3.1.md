# 四季光伏工具箱 v0.3.1 安装器验证记录

## 验证结论

2026-08-26在本机完成最终候选静态检查，以及引用该候选冻结payload的隔离安装器
运行回归。候选、隔离staging和实际安装的AutoCAD 2020（R23.1）DLL逐字节一致。
三类日志均具有只能在全部步骤完成后写入的终态成功标记。

本记录证明安装器控制逻辑和冻结payload的自动化行为；不证明最终候选EXE自身已经
完成系统级安装，也不证明系统级`v0.2.0 -> v0.3.1`管理员升级、完整GUI或其他
AutoCAD版本已经通过。

## 冻结顺序

```powershell
pwsh -File .\scripts\test.ps1

pwsh -File .\scripts\package-installer.ps1 `
  -AllowUnsignedDevelopmentBuild -AutoCADDir "D:\cad\AutoCAD 2020"
pwsh -File .\scripts\installer\Test-InstallerArtifacts.ps1 `
  -BuildDirectory .\work\installer\release-candidate-v0.3.1

pwsh -File .\scripts\package-installer.ps1 `
  -TestCurrentPayload `

  -AutoCADDir "D:\cad\AutoCAD 2020"

  -BuildDirectory .\work\installer\test-v0.3.1
```

## 静态与发布链检查

- schema 4绑定源码指纹、关键构建输入、SDK provenance、manifest、inventory、
  source/staged DLL和EXE哈希。
- `acmgd.dll`、`acdbmgd.dll`、`accoremgd.dll`程序集版本均为
  `23.1.0.0`，签名均为Autodesk `Valid`。
- release manifest只激活R23.1；2018-2019及2021-2026仍为候选。
- 安装器核对注册表Series、Release、安装路径和`acdbmgd.dll`版本。
- 安装器不写`SECURELOAD`、`TRUSTEDPATHS`或其他CAD系统变量。
- `TEST_UNSIGNED`要求源DLL、staged DLL和EXE全部严格为`NotSigned`。
- 正式模式要求DLL、EXE和卸载器使用允许列表内的同一可信证书并带时间戳；
  当前允许列表为空，因此正式构建失败关闭。
- 最终交付目录由发布证据脚本限制为五个顶层文件。
