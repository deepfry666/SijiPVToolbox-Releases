# 导轨对齐标注独立方案 v0.1.0

- 日期：2026-09-02
- 对应问题：`ISSUE-0015`
- 输入基线：用户提供的 `导轨对齐标注(3).lsp`
- 原附件 SHA-256：`4C901CBEFB794C203FF692053E58A90BEDF08BA89326595B786024D7CE233D55`
- 交付形态：独立 AutoLISP 插件，不接入主工具箱和正式安装包

## 1. 方案定位

当前四季光伏工具箱 `STPVRAIL` 的正式边界仍是“只画导轨，不生成、修改或删除尺寸”。
本方案不恢复 `v0.3.5` 已取消的旧全自动标注器，而是把用户提供的 LSP 整理成一个可以
独立加载、验证和回退的“已有导轨对齐标注”插件。现场认可之前，两者不联动。

## 2. 识别流程

1. 用户选一根示例导轨和一个示例组件。
2. 用户可连续框选多个处理窗口，程序合并选择集并自动去重。
3. 导轨按图层、可见颜色和实体类型匹配；组件在此基础上增加块名或闭合轮廓匹配。
4. 边界距离不大于 `200 mm` 的组件归为同一阵列。
5. 同一阵列内，长度差不大于 `1 mm` 的导轨只保留一根外侧代表导轨。
6. 对代表导轨生成“导轨起点到组件边、组件阵列宽度、组件边到导轨终点”的尺寸段；
   符合方向和距离条件的前后导轨增加跨接尺寸。
7. 鼠标位置决定主标注带一侧和外移距离；次导轨使用固定 `700 mm` 外移，避免完全重合。

## 3. 输出与安全

- 输出为原生 `AlignedDimension` / `RotatedDimension`。
- 优先继承 `TSSD_100_100`、`100:100` 或 `100：100`；均不存在时明确提示按 1:1 降级。
- 创建过程保存并恢复 `CMDECHO`、`DIMSCALE` 和 `DIMLFAC`。
- 全部新尺寸组成一个撤销组；一次 `UNDO` 整批撤销。
- 中途失败时删除本次已经创建的尺寸，既有导轨、组件及人工标注不变。
- 重复运行不静默删除旧标注，避免误伤人工成果；首版由用户自行决定是否保留前次结果。

## 4. 编码与兼容

仓库源文件为 UTF-8，便于 Git 审查；`build-rail-annotation.ps1` 将交付文件转换为 GBK
代码页 936，规避 AutoCAD 2020 对中文 AutoLISP 源文件的编码兼容风险。工程命令为
`STPVRAILANNOTATE`，并保留原 `GDBZ` 命令。

## 5. 验证边界

自动化覆盖源文件门禁、UTF-8 到 GBK 往返、独立模块边界、二维几何、样例匹配、组件
阵列分组、代表导轨选择、六段原生尺寸创建、一次 `UNDO`、保存重开以及原始模板哈希
不变。动态鼠标预览、多窗口人工选择、块组件视觉效果和真实工程图排版仍需 GUI 现场复测；
这些项目未通过前不接入主工具箱。
