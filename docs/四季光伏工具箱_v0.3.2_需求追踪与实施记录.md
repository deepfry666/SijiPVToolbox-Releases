## 1. 版本目标

`v0.3.2`不改变导轨生成和实际尺寸规划规则，集中解决两个标注避让缺口，并提高安装
可理解性和版本追溯性：

1. 外部障碍和前序标注组按当前标注方向转换到共同局部坐标系，修复旋转屋面使用
   世界坐标包围框造成的假碰撞和假耗尽。
2. 用确定性约束求解器替代顺序 first-fit；使用前向检查和完整回溯，在配置的有限
   车道域内区分“顺序选错”和“真实无解”。
3. 安装器把`acad.exe`固定 FileVersion和 ProductVersion纳入宿主身份判断，并明确显示可以安装/当前不支持、
   全新安装/升级关系以及重启后输入`JJJJ`。
4. 冻结`v0.3.1`源码与交付基线，保留独立`v0.3.2`源码、日志、MVID、JSON和
   SHA-256证据链。

## 2. 用户需求确认

本版延续已经确认的产品规则：

- 首页和Ribbon只有“自动画导轨”；导轨标注属于该流程内部能力。
- `STPVRAILANNOTATE`只用于已有导轨单独重标，不增加首页功能页。
- 导轨垂直组件长边；第一版不做短边方案。
- 默认每块组件2根导轨、首末总间距1400 mm、贯通净距20 mm、两端各伸出100 mm。
- 导轨默认图层“导轨”、ACI 6洋红色、全局宽度0；名称、颜色和宽度可修改。
- 所有导轨尺寸按最终实际几何标注，不按默认参数反推。
- 复杂屋面的尺寸要自动避让；无法可靠求解时整批回滚，不静默提交重叠结果。
- 距屋面边、女儿墙、轴线或底图轮廓的定位仍由用户手工标注。
- 工具面向可安装、可升级的软件交付，但正式公开前必须有可信代码签名。

## 4. 旋转碰撞修复

### 4.1 共同局部坐标系

`RailAnnotationDrawingService.BuildCollisionFrames`从每个标注集合的测量方向建立标准化
坐标轴；平行同向集合复用同一个`CollisionFrame`。收集模型空间障碍时，每个实体都会
投影到每个相关frame：

- 支持方向几何的尺寸、块、Line、Polyline、文字、实体、圆弧、圆和椭圆，优先拆解
  或按实际几何取得局部范围；
- 源组件/导轨使用关键范围参与判断；
- 已经放置的前序尺寸组会重新取得完整实体几何并登记到全部相关frame；
- 无法取得受支持对象局部几何时失败即停；未知对象只能使用转换后的粗范围，可能仍
  保守，但不会把世界坐标AABB直接与旋转候选尺寸比较。

候选尺寸、外部障碍和前序组最终在同一个局部坐标系中比较，修复了`v0.3.1`记录的
外部AABB保守外移缺口。

### 4.2 确定性完整回溯

`Core/DeterministicLaneSolver.cs`把每个尺寸视为变量，把`0..MaximumLanes`视为有限域：

1. 先预计算每个尺寸在每条车道上是否避开外部障碍；
2. 同组候选对按局部关键几何建立冲突约束；
3. 使用最小剩余值选择下一变量，车道始终按升序尝试；
4. 每次赋值后执行前向检查，域被清空时立即回溯；
5. 没有搜索节点预算或静默提前停止；有限域穷尽后才报告真实无解；
6. 结果、访问节点数和回溯数在相同输入下保持确定。

求解器目标是找到一个确定的可行解，不声明全局最少车道或最短总外移优化。车道仍限于
现有配置`0..24`；超过边界不自动扩张，无解时由上层事务整批回滚。

## 9. 尚需人工验收

1. 保存图纸并关闭CAD后，执行本机系统级`v0.2.0 -> v0.3.2`管理员升级。
2. 启动或重启CAD，输入`JJJJ`，核对实际加载版本`0.3.2.0`。
3. 在100% DPI检查首页首次完整显示、预览、换边、取消、`UNDO`和复杂屋面避让。
4. 经用户同意后再检查125%和150% DPI。
5. 分别在尽可能干净的原版AutoCAD 2020与探索者环境检查GUI、Ribbon、尺寸样板和提示。
6. 正式公开前配置可信代码签名并在干净电脑复验。

当前只能声明AutoCAD 2020 R23.1 CoreConsole核心运行已验证。GUI、探索者、系统级
`v0.2.0 -> v0.3.2`升级和其他CAD版本均不能写成已通过。
