# 四季光伏工具箱 v1.0.4 安装与兼容性说明

- 软件版本：`v1.0.4`
- 程序集版本：`1.0.4.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v1.0.4.exe`
- 前一版本：`v1.0.3`

## 本次变更

在线更新停止使用 VPS。客户端只读取公开 GitHub Release 的
`latest/download/stable.json`，安装包主地址直接指向同版本 GitHub Release 资产。
下载仍要求 HTTPS，并核对清单声明的文件大小和 SHA-256。

已发布的 `v1.0.3` 会优先读取 VPS 的旧清单，无法自动发现本版本，因此需要手动安装
`v1.0.4` 一次。从 `v1.0.4` 开始，后续版本可直接通过工具箱从 GitHub 检查和下载。

导轨、配重和单墩统计保持 `v1.0.3` 的功能与数据格式，正式包继续只含五个模块。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v1.0.4.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，确认首页显示版本 `1.0.4`。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。当前安装包和五个 DLL 没有
Authenticode 代码签名，Windows 可能显示“未知发布者”。
