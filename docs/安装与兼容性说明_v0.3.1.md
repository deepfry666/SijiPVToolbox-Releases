# 四季光伏工具箱 v0.3.1 安装与兼容性说明

## 发布状态

`v0.3.1`安装器采用Inno Setup 6生成单文件EXE。当前程序集、bundle manifest和
安装器版本已经同步为`0.3.1.0`。开发阶段的EXE先在`work/`中构建和验证；通过后
可复制到带`_TEST_UNSIGNED`后缀的`outputs/`目录供本机验收。该目录名、说明文件和
验证摘要都必须明确标注“未签名测试版”，不得作为正式软件对外发布。正式公开目录
不带`_TEST_UNSIGNED`后缀，并且DLL和安装器都必须具有可信代码签名。

本说明中的“候选”只表示已规划的适配目标，不表示已经兼容。候选版本不会被写入
正式release manifest，也不会由安装器强行加载。

## 安装方式

1. 保存图纸并完全关闭AutoCAD及AutoCAD Core Console。
2. 双击`四季光伏工具箱_Setup_v0.3.1_TEST_UNSIGNED.exe`。文件名、Windows文件属性、
   安装向导和“已安装的应用”都会显示`TEST_UNSIGNED 未签名测试版`。
3. 检查安装器列出的AutoCAD版本和支持状态。
4. 默认选择“仅为我安装”，无需管理员权限。
5. 只有需要让本机所有Windows用户共用插件时，才选择“为所有用户安装”并同意UAC。
6. 安装完成后启动已支持的AutoCAD，输入`JJJJ`打开工具箱。

## 功能入口

- 首页和Ribbon只提供“自动画导轨”，导轨标注是该流程内部的可选能力，不作为第二个
  功能页或同级入口。
- `STPVRAILANNOTATE`命令保留给已有导轨的单独重标，不出现在首页或Ribbon。
- `JJJJ`只打开首页，`STPVRAIL`直接启动自动画导轨。

安装器不要求用户选择目录，也不会修改AutoCAD的`SECURELOAD`或
`TRUSTEDPATHS`。每用户安装使用Autodesk标准目录：

`%APPDATA%\Autodesk\ApplicationPlugins\ZhStructureToolbox.bundle`

全用户安装使用：

`%ProgramFiles%\Autodesk\ApplicationPlugins\ZhStructureToolbox.bundle`

`UNDO`、系统级升级和卸载另列人工验收状态，不能由“核心已验证”代替。

AutoCAD 2018-2019及2020以后的每个版本都必须取得对应Autodesk API程序集完成构建，
并先在对应 CoreConsole 中完成同哈希运行验证，核心兼容状态才能从“候选”改为
“CoreConsole 已验证”。随后还必须在真实 AutoCAD 或隔离测试机上分别记录加载、
Ribbon、工具箱、画轨、标注、`UNDO`、升级和卸载的 GUI/外部验收结论。AutoCAD 2025
及以后必须使用独立的.NET 8模块，不能复用当前.NET Framework DLL。

安装前，安装器同时核对注册表Series、注册表Release、安装目录以及
`acdbmgd.dll`版本；三者不一致或文件缺失时按检测异常处理，不会把该宿主视作已验证
版本。构建端还会核对`acmgd.dll`、`acdbmgd.dll`、`accoremgd.dll`的程序集版本、
SHA-256和Autodesk签名。当前构建配置只允许`acad2020-netfx / R23.1`；其他Series即使
目录中存在同名DLL也会停止，不能误写为R23.1产物。

## 升级和迁移

- 安装器在用户目录和系统目录同时检查旧bundle。
- 只有`ProductCode`和`UpgradeCode`属于本产品时，安装器才允许迁移或删除。
- 发现未知同名目录时立即停止，不覆盖用户文件。
- 已有系统级旧版时，必须选择全用户模式完成迁移，避免用户目录和系统目录出现两份插件。
- 安装前将旧bundle改名备份；安装失败会恢复，成功后才清理备份。
- 普通安装禁止降级；支持人员可使用显式维护参数处理经过确认的降级。
- AutoCAD运行期间禁止安装、升级和卸载，安装器不会强制结束进程。

当前自动化回归已覆盖隔离的当前用户安装、同版本升级、失败回滚、降级阻止和卸载。
隔离安装器必须引用最终候选的冻结`build-result.json`，并在安装后核对payload哈希，
因此运行回归使用的DLL与候选DLL逐字节一致。由于测试安装器使用隔离产品身份，最终
候选EXE自身仍需在关闭AutoCAD后进行系统级人工升级验收。
本机现有系统级`v0.2.0`升级到`v0.3.1`涉及管理员权限和真实旧安装，必须在关闭
AutoCAD后由用户或干净测试机单独验收；在完成前不声明该路径已实机通过。

## 卸载和设置

EXE安装后可在Windows“设置 > 应用 > 已安装的应用”中卸载，也可使用开始菜单的
卸载入口。卸载器同样核验产品身份并要求AutoCAD关闭。

卸载和升级默认保留：

`%APPDATA%\StructuralToolbox`

其中包含用户参数和界面布局记录。安装器不删除DWG文件。

## 更新准备

安装器使用稳定的Inno `AppId`和Autodesk `UpgradeCode`。后续自动更新应下载完整、
已签名的EXE，校验SHA-256和可信发布者签名，等待AutoCAD退出后再调用同一安装器。
禁止在AutoCAD进程中直接覆盖已加载的DLL。

公开发布前必须使用真实发布者身份，对安装EXE、卸载器、更新助手和全部DLL执行
Authenticode SHA-256签名并加入可信时间戳。测试构建可以无签名，但不得放入
无明确`_TEST_UNSIGNED`后缀的正式目录，也不得对外发布。正式构建要求先由
`PayloadSignScript`签署fresh build产生的每个DLL并校验有效签名，再由Inno签名命令
签署安装EXE和卸载器；任一步缺失或签名无效都会停止构建。

交付目录中的`SHA256SUMS.txt`独立列出EXE、说明、摘要和发布证据JSON的SHA-256，
用于发现下载或复制造成的意外变化。`TEST_UNSIGNED`没有可信发布者数字签名；攻击者
可以同时替换文件和校验清单，因此该清单不能证明发布者身份，也不能替代正式签名。
