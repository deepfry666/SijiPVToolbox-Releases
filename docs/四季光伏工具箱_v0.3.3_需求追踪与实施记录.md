## 用户确认事项

| ID | 已确认要求 | 本版处理 |
|---|---|---|
| COMPAT-001 | 尽可能兼容多版本，不能兼容时按 CAD 版本判断 | 兼容矩阵按 Series、Release、acad.exe 两种版本和 acdbmgd 版本判断；仅 R23.1 进入当前 payload |
| COMPAT-002 | 当前电脑只有 AutoCAD 2020 | 以 AutoCAD 2020 Win64 R23.1 为唯一已验证目标，其他版本保留候选记录 |
| INSTALL-001 | 直接安装、以后可更新 | 采用单 EXE；稳定 AppId/UpgradeCode/ProductCode 保留升级链，在线更新服务仍未实现 |
| INSTALL-002 | 安装提示要明显 | 兼容页显示目标和“可以安装/当前不支持”，不支持宿主点击下一步即阻止 |
| INSTALL-003 | 可溯源 | 版本化文档、源快照、SDK provenance、build-result、日志和 SHA-256 发布证据链 |
| INSTALL-004 | 正式软件不能把未签名版当正式版 | `TEST_UNSIGNED` 显著标识；正式模式缺少可信签名时失败关闭 |
| INSTALL-005 | 旧版本可升级且不能误删陌生目录 | 稳定身份和旧 ProductCode 保留；陌生同名 Bundle 停止；备份失败回滚 |

## 当前未闭合事项

1. 并发中的导轨标注碰撞修复尚未通过 AutoCAD CoreConsole；在该回归稳定前不能冻结
   `v0.3.3` DLL、EXE 或发布哈希。
2. AutoCAD 2018-2019、2021-2026 没有对应 payload 和实机证据，仍须标为候选。
3. GUI、探索者、SmartScreen/UAC、系统级旧版升级和真实用户图纸验收尚未完成。
4. 正式公开版的签名证书、时间戳服务和允许指纹尚未配置；当前只能交付未签名本机版。
5. 旧 `v0.2.0` 没有当前 Inno AppId；自动化没有在真实系统范围执行正式旧 Bundle 迁移，
   因此只能写“身份规则已覆盖、真实升级待验收”。

## 追溯规则

每次发布必须将版本、程序集、manifest、源/staged/实际加载 DLL、安装器 EXE、验证日志
和五项交付文件写入 SHA-256；只允许当前版本进入 `outputs/`，旧版本放入
`work/legacy-output/`，并在文档中记录“已安装版本”和“新建版本”是否需要重启后切换。
