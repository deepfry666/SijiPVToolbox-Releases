# 四季光伏工具箱 v0.4.1 安装器实施记录

- 目标版本：`v0.4.1` / 程序集 `0.4.1.0`
- 交付目录：`SijiPVToolbox_v0.4.1_AutoCAD2020`
- 交付文件：`四季光伏工具箱_Setup_v0.4.1.exe`
- 发布分类：`UNSIGNED`
- Authenticode 预期：`NotSigned`
- 稳定清单：`https://download.imfourj.cn/fourj-pv-toolbox/stable.json`

## 实施内容

- 更新能力先在 `StructuralToolbox.Update` 独立项目中完成构建、版本比较、清单解析、
  HTTPS 下载、文件大小和 SHA-256 校验测试，稳定后才作为第五模块接入总 Bundle。
- 正式更新源编入更新 DLL，避免松散配置文件把用户静默重定向到其他下载源。
- 清单检查和安装包下载使用后台线程；失败结果返回 UI，绘图界面不等待网络请求。
- 更新模块只下载完整 EXE，不复制或替换 AutoCAD 已加载的 DLL。
- 静态下载服务包含下载页、`stable.json`、版本化安装包目录、Nginx 示例以及站点
  一致性测试，不依赖数据库或后台应用进程。
- 安装器将原兼容性长文本改为紧凑安装信息页，直接列出主要功能、AutoCAD 检测结论、
  用户级/系统级固定插件路径和同范围升级要求，详细身份信息保留在日志中。

## 未签名发布边界

用户已确认本阶段不会配置可信代码签名。`release-v0.4.1.json` 因此固定记录
`UNSIGNED`、`NotSigned` 和空签名者指纹列表；打包器仍会拒绝意外混入部分签名或
与发布定义不一致的文件。

HTTPS、固定域名、版本化下载路径、大小和 SHA-256 校验继续作为当前完整性控制。
SHA-256 不能替代发布者签名，这一剩余风险保留在安装说明和更新手册中。

## 发布控制

稳定 ProductCode、UpgradeCode、安装范围标识和已接受的 v0.2.0 ProductCode 沿用前版。
普通安装禁止降级；安装、升级和卸载仍要求 AutoCAD 已关闭。最终 `outputs/` 只保留
当前版本目录，上一稳定正式包进入受保护的历史回滚目录。
