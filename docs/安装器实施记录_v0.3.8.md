## 功能变更

v0.3.8 将配重边界校验拆分为两条硬约束：配重外轮廓不得越出组件边界；
配重中心点到组件边缘的距离不得超过 `800 mm`。旧配置中的允许越界字段仅保留 XML
兼容读取，加载后统一归零。

默认仍按组件阵列自身方向前后对称布置。自定义模式只输入前侧中心边距和相邻
配重中心距，后侧边距按阵列纵向长度和配重数量自动计算；外轮廓越界、中心边距超限
或前侧边距与配重间距互相矛盾时，拒绝生成并返回明确错误。按组件排数保存默认参数，
特殊阵列可通过 `STPVBALLASTARRAYSETTINGS` 单独覆盖。

配重设置增加高度、统一自定义图层和每种尺寸的颜色。尺寸首次出现时保留 ByLayer，
其他尺寸使用 ACI 默认色序列，用户指定的 ACI 或 TrueColor 优先。配重高度仅写入工具元数据
和统计规格，不改变平面轮廓。

新增通用数量表服务以及 `STPVBALLASTSTAT`、`STPVRAILSTAT` 两个框选统计命令。配重按
形状、平面尺寸和高度分类，工具生成的一槀会展开为独立配重块数量；导轨统计总长并
换算为米。两类对象均支持生成后立即统计和后续框选统计，并可选择仅统计工具对象或
统计指定图层内的全部合格对象。

## 精简内容

最终 `outputs/` 只保留当前版本目录和 `archive/`。旧版本安装包移动到
`outputs/archive/`，不会与当前安装包混淆。构建 inventory、兼容矩阵、安装说明、
验证日志、哈希和回执保留在 `work/`，不重复嵌入安装包。

EXE 只携带 AutoCAD Bundle 必需的 `PackageContents.xml` 和 R23.1
`StructuralToolbox.dll`。安装向导取消欢迎页、签名分类警告页、Ready 摘要页和开始
菜单文档入口，只保留宿主兼容性页以及 Inno Setup 必需的安装进度和完成页。

## 保留的安全控制

- AutoCAD、Core Console 和探索者进程关闭检查；
- AutoCAD 2020 R23.1 注册表、`acad.exe` 和 `acdbmgd.dll` 一致性检查；
- 当前用户/所有用户安装范围冲突检查；
- ProductCode、UpgradeCode 所有权检查；
- 升级、普通降级阻止、安装前备份和失败恢复；
- 卸载前宿主关闭检查，且只删除本产品 Bundle；
- 不修改 `SECURELOAD`、`TRUSTEDPATHS` 和用户工具设置。

签名元数据没有隐藏或伪造：发布定义、构建结果和产物验证仍要求并记录
`Authenticode=NotSigned`。
