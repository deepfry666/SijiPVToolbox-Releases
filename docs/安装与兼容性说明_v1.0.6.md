# 四季光伏工具箱 v1.0.6 安装与兼容性说明

- 软件版本：`v1.0.6`
- 程序集版本：`1.0.6.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v1.0.6.exe`
- 前一版本：`v1.0.5`

## 本次变更

首页和 Ribbon 新增“导轨对齐标注”。该功能原样内置用户提供的 `导轨对齐标注 V1.0`
（AutoLISP 命令 `GDBZ`），通过工具箱命令 `STPVRAILDIM` 运行：命令先校验内置脚本的
SHA-256，再释放到 `%LOCALAPPDATA%\StructuralToolbox\rail-dimension\V1.0\`，加载后
直接开始 `GDBZ` 流程。首次运行后，同一图纸也可直接输入 `GDBZ`。

脚本嵌入 `StructuralToolbox.Rail.dll`，正式包继续只含五个模块，Bundle 和安装器文件集
不变。`%APPDATA%\StructuralToolbox` 中的导轨、配重和更新设置不读写；自动画导轨、
配重、统计和在线更新保持 `v1.0.5` 的行为。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v1.0.6.exe`，或在已安装 `v1.0.5` 的“检查软件更新”页
   下载后运行。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，确认首页显示版本 `1.0.6` 和“导轨对齐标注”。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。当前安装包和五个 DLL 没有
Authenticode 代码签名，Windows 可能显示“未知发布者”。
