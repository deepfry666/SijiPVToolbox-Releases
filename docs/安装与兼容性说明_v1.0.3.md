# 四季光伏工具箱 v1.0.3 安装与兼容性说明

- 软件版本：`v1.0.3`
- 程序集版本：`1.0.3.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v1.0.3.exe`
- 前一版本：`v1.0.2`

## 本次变更

配重仍按“一榀一个外层块”生成，移动、删除和重新生成操作保持不变。框选统计改为进入
每个配重榀，按单墩中心逐个识别并计数；模型空间中单独复制的标准单墩直接计为一个。
手画圆墩或闭合矩形可使用“点选识别单墩”确认规格，标记后的实体及其复制件均可统计。

在线更新增加 VPS 与 GitHub 清单回退以及多个安装包下载地址回退。无论使用哪条线路，
客户端都继续要求 HTTPS，并核对清单声明的文件大小和 SHA-256。

`v1.0.3` 保持 `v1.0.2` 的五模块发布边界，不包含独立组件构件模块或混凝土屋面支架
大样模块。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 运行 `四季光伏工具箱_Setup_v1.0.3.exe`。
3. 安装信息页显示 AutoCAD 2020“可以安装”后继续；未检测到 AutoCAD 时允许预先安装。
4. 升级时选择与旧版相同的安装范围。
5. 安装完成后启动 AutoCAD，输入 `JJJJ`，确认首页显示版本 `1.0.3`。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。当前安装包和五个 DLL 没有
Authenticode 代码签名，Windows 可能显示“未知发布者”。
