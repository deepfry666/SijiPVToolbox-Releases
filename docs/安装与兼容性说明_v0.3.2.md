# 四季光伏工具箱 v0.3.2 安装与兼容性说明

## 发布状态

本安装包是`v0.3.2 TEST_UNSIGNED`未签名测试版，程序集、bundle manifest和安装器
版本均为`0.3.2.0`。它只用于本机验收，不得作为正式软件公开分发。

Windows可能显示“未知发布者”或 SmartScreen 提示。请只从确认的项目交付目录取得
安装包，并用同目录`SHA256SUMS.txt`和发布证据 JSON 核对文件。SHA-256可发现复制或
下载中的意外变化，但未签名测试版没有可信发布者身份，校验清单不能替代数字签名。

## 安装前先确认

1. 保存全部图纸。
2. 完全关闭 AutoCAD、探索者环境以及 AutoCAD Core Console。
3. 如果任务管理器中仍有`acad.exe`或`accoreconsole.exe`，先正常结束相应程序。
4. 本机已有系统级`v0.2.0`时，本次必须选择“为所有用户安装”并同意 UAC；不要再
   安装一份当前用户版本。

安装器不会强制关闭 AutoCAD，也不会替用户保存图纸。检测到 CAD 仍在运行时，安装、
升级和卸载都会停止。

## 安装步骤

1. 双击`四季光伏工具箱_Setup_v0.3.2_TEST_UNSIGNED.exe`。
2. 阅读`TEST_UNSIGNED 未签名测试版`提示。
3. 在兼容性页检查每个 AutoCAD 宿主的身份信息和结论。只有显示
   “【结论：可以安装】”的宿主会获得插件；“【结论：当前不支持】”表示本安装包
   不会加载。
4. 全新安装默认选择“仅为我安装”，无需管理员权限。
5. 迁移本机已有的系统级`v0.2.0`时，选择“为所有用户安装”并同意 UAC。
6. 在准备安装页确认是“安装类型：全新安装（未检测到已安装的受管版本）”还是
   “升级关系：<最高受管版本> -> 0.3.2.0”。
7. 安装完成后，按提示先启动或重启 AutoCAD，再在命令行输入`JJJJ`打开
   四季光伏工具箱。

当前用户安装目录：

`%APPDATA%\Autodesk\ApplicationPlugins\ZhStructureToolbox.bundle`

全用户安装目录：

`%ProgramFiles%\Autodesk\ApplicationPlugins\ZhStructureToolbox.bundle`

安装器不要求用户另选目录，不修改 AutoCAD 的`SECURELOAD`、`TRUSTEDPATHS`或 DWG。

## 当前兼容范围

“CoreConsole 已验证”只表示使用匹配 Series 的 Autodesk API 构建，并在同一 Series
的 AutoCAD CoreConsole 中完成真实数据库运行验证。它不等于完整 GUI、Ribbon、
探索者、交互、系统级升级或卸载已经验收。

| AutoCAD | Series | 运行时 | 核心状态 | GUI/外部验收 | 本安装包结论 |

| 2018 | R22.0 | .NET Framework | 候选 | 未开始 | 当前不支持 |
| 2019 | R23.0 | .NET Framework | 候选 | 未开始 | 当前不支持 |
| 2020 | R23.1 | .NET Framework | CoreConsole真实数据库验证通过 | GUI、探索者及系统级升级待验收 | 可以安装 |
| 2021 | R24.0 | .NET Framework | 候选 | 未开始 | 当前不支持 |
| 2022 | R24.1 | .NET Framework | 候选 | 未开始 | 当前不支持 |
| 2023 | R24.2 | .NET Framework | 候选 | 未开始 | 当前不支持 |
| 2024 | R24.3 | .NET Framework | 候选 | 未开始 | 当前不支持 |
| 2025 | R25.0 | .NET 8 | 候选 | 未开始 | 当前不支持 |
| 2026 | R25.1 | .NET 8 | 候选 | 未开始 | 当前不支持 |

当前唯一已验证的核心宿主是 AutoCAD 2020 Win64 Series`R23.1`。其他年份只是规划的
适配候选，未取得对应 SDK 构建和同 Series 运行证据前，不会写入加载清单。
AutoCAD 2025及以后必须使用独立`.NET 8`模块，不能复用当前`.NET Framework` DLL。

安装器同时核对注册表 Series、Release、安装路径、`acad.exe`固定 FileVersion、
`acad.exe` ProductVersion和`acdbmgd.dll`版本。部分第三方环境会改写固定
FileVersion；此时安装器仍要求 ProductVersion与Series一致，并在检测页同时显示两项，
不会把差异隐藏。两个`acad.exe`版本字段至少一个必须与Series一致，同时注册表Release
和托管API版本也必须一致，否则显示“【结论：当前不支持】”。

## 功能入口

| 命令 | 作用 |
|---|---|
| `JJJJ` | 打开“四季光伏工具箱”首页 |
| `STPVRAIL` | 直接运行“自动画导轨” |
| `STPVRAILANNOTATE` | 对已有导轨单独重标，不设首页或 Ribbon 同级入口 |
| `STTOOLBAR` | 尝试恢复顶部 Ribbon 页签 |
| `STABOUT` | 显示版本和已验证兼容范围 |

Ribbon创建失败不会阻断核心命令，仍可输入`JJJJ`或直接命令。

## v0.3.2 标注避让改进

本版修复旋转屋面的两个保守误判来源：外部障碍与前序标注组现在都会按当前标注方向
投影到共同的局部坐标系，再与候选尺寸比较；不再直接用世界坐标包围框判断旋转对象。

车道分配由顺序 first-fit 改为确定性约束求解。求解器使用固定顺序、前向检查和完整
回溯：只要配置的`0..24`车道内存在满足全部约束的组合，就会找到一个确定结果；若
确实无解，则整批取消并回滚，不留下部分尺寸、XData、匿名尺寸块或临时图层。

这项改进减少旋转屋面上的假碰撞和假耗尽，不代表可以识别任意屋面语义。距屋面边、
女儿墙、轴线或底图轮廓的定位尺寸仍由用户手工标注。

## 升级、卸载和设置

- 安装器同时检查当前用户和全用户插件目录。
- 只迁移属于本产品稳定 ProductCode/UpgradeCode 的版本；未知同名目录会停止处理。
- 升级前备份旧 bundle；失败恢复，成功后才清理备份。
- 普通安装禁止降级。
- Windows“设置 > 应用 > 已安装的应用”和开始菜单均提供卸载入口。
- 升级和卸载默认保留`%APPDATA%\StructuralToolbox`中的参数和界面布局。

本机系统级`v0.2.0 -> v0.3.2`升级、完整 GUI 和探索者环境仍需在用户保存图纸并关闭
CAD后实机验收。在该验收完成前，只能声明 AutoCAD 2020 R23.1 CoreConsole 核心运行
已验证，不能把系统级升级或探索者兼容写成已通过。

## 当前不支持

- 短边布置方案；
- 自动判断屋面边界、女儿墙或底图语义；
- 块参照或 Xref 内组件；
- 弯折、圆弧或 3D 导轨；
- AutoCAD LT、AutoCAD for Mac、浩辰 CAD 和 ZWCAD；
- AutoCAD 2018-2019、2021-2026 的实际加载；
- 在线更新、后台下载和静默更新。

## 更新与正式发布边界

`v0.3.2`只保留稳定产品身份、完整 EXE 升级路径和签名校验基础，尚未实现在线更新
服务。后续更新功能应下载完整且已签名的 EXE，校验 SHA-256和可信发布者，等待 CAD
退出后再调用安装器；禁止在 CAD 进程中直接覆盖已加载 DLL。

正式公开发布前，必须对全部插件 DLL、安装 EXE 和卸载器执行可信代码签名
（Authenticode SHA-256）并加入可信时间戳，再在干净电脑复验安装、升级、卸载和 GUI。当前
`TEST_UNSIGNED`版本不得直接发给更多用户作为正式软件。
