# 四季光伏工具箱 v0.3.9 安装与兼容性说明

- 软件版本：`v0.3.9`
- 程序集版本：`0.3.9.0`
- 支持宿主：AutoCAD 2020 Win64，Series `R23.1`
- 交付文件：`四季光伏工具箱_Setup_v0.3.9.exe`
- 前一版本：`v0.3.8`

新构建的 `v0.3.9` 不等于当前已经加载。保存图纸并完全关闭 AutoCAD、探索者和
AutoCAD Core Console，完成升级并重新启动 AutoCAD 后才会切换到新版本。

## 本次变更

按组件排数设置和特殊阵列覆盖中，选择“自定义前侧”后显示配重俯视示意图。
示意图以组件阵列自身方向标出前侧、前侧中心边距 `F`、相邻配重中心间距 `S`
和自动计算的后侧边距。输入栏同步改为“前侧中心边距 F”和“配重中心间距 S”，
明确这两个值都以配重中心点为基准。默认前后对称模式下示意图隐藏，不额外占用界面。

工具箱固定按 `1 图纸单位 = 1 mm` 计算。本版其他配重布置、分尺寸统计、
导轨统计和安装安全边界延续 `v0.3.8`。统计表仅通过手动框选统计命令生成，自动布置和
自动画导轨流程不再插入统计表。

## 安装与兼容边界

1. 保存图纸，完全关闭 AutoCAD、探索者和 AutoCAD Core Console。
2. 双击安装 EXE。
3. 兼容性页显示 AutoCAD 2020 R23.1“可以安装”后继续。
4. 安装完成后启动 AutoCAD，输入 `JJJJ`。

只有 AutoCAD 2020 Win64 R23.1 进入当前加载清单。其他 AutoCAD 年份、AutoCAD LT、
Mac、浩辰和 ZWCAD 不属于本安装包支持范围。安装器不修改 `SECURELOAD` 或
`TRUSTEDPATHS`。

当前安装包没有 Authenticode 代码签名，Windows 可能显示“未知发布者”。内部构建
回执如实记录 EXE 和 DLL 的 `NotSigned` 状态及 SHA-256。
