# 四季光伏工具箱 v1.0.6 安装器实施记录

- 目标版本：`v1.0.6` / 程序集 `1.0.6.0`
- 交付目录：`SijiPVToolbox_v1.0.6_AutoCAD2020`
- 交付文件：`四季光伏工具箱_Setup_v1.0.6.exe`
- 发布分类：`UNSIGNED`
- Authenticode 预期：`NotSigned`

## 实施内容

- 用户提供的 `导轨对齐标注_V1.0.lsp` 逐字节保存为
  `src/StructuralToolbox.Rail/Resources/GDBZ_V1.0.lsp`（GBK、LF，SHA-256
  `ACDA16C65A5430E79740B599AB7A40432C8B20C5FB6BD6075AA313EC48AEF2BC`），由
  `scripts/build-rail.ps1` 以 `StructuralToolbox.Rail.Resources.GDBZ_V1.0.lsp` 嵌入
  导轨 DLL；`.gitattributes` 禁止换行转换。
- 导轨模块新增 `STPVRAILDIM`：读取嵌入资源并校验 SHA-256，释放或复用
  `%LOCALAPPDATA%\StructuralToolbox\rail-dimension\V1.0\GDBZ_V1.0.lsp`，再通过一条
  `load` 表达式加载并执行 `c:GDBZ`。不注册同名 .NET `GDBZ` 命令，避免遮蔽 LISP 命令。
- 新增首页模块“导轨对齐标注”（`DisplayOrder=150`）和独立操作页，页面列出 V1.0 规则并
  显示 `G`/`E` 规则示意图；Ribbon 在“自动画导轨”和“自动布置配重”之间增加同名按钮。
- Bundle manifest 声明 `STPVRAILDIM`；About 文本列出新功能和命令。
- 五个正式程序集、Bundle、首页、About、README 和安装器统一为 `1.0.6.0`。

## 发布控制

稳定 ProductCode、UpgradeCode、安装范围标识和已接受的旧 ProductCode 沿用前版。
普通安装禁止降级；安装、升级和卸载仍要求 AutoCAD 已关闭。在线更新继续只使用
GitHub Release，并保留 HTTPS、文件大小和 SHA-256 校验，更新机制本身没有修改。

正式发布必须在维护者 Windows 机器上执行，顺序与 `v1.0.5` 相同：

1. `scripts/build.ps1 -AutoCADDir "D:\cad\AutoCAD 2020"` 重建五个 Bundle DLL 并提交
   （`scripts/test.ps1` 的 Built 体检要求已提交 DLL 为 `1.0.6.0`）。
2. `scripts/Build-ReleaseCandidate.ps1 -Version 1.0.6 -AutoCADDir "D:\cad\AutoCAD 2020" -RunInstallerRuntimeTest`。
3. `scripts/verify-autocad2020.ps1 -Version 1.0.6 -AutoCADDir "D:\cad\AutoCAD 2020"`，并按
   开发发布手册完成 GUI 人工检查（含导轨对齐标注页和 Ribbon 按钮）。
4. `scripts/Publish-TestRelease.ps1 -Version 1.0.6 -BuildResult work\installer\release-candidate-v1.0.6\build-result.json`，
   再执行 `scripts/Test-ReleaseReadiness.ps1 -Version 1.0.6 -Phase Published`。
5. `scripts/update-service/New-UpdateRelease.ps1 -Version 1.0.6 -InstallerPath <正式 EXE>
   -SourceRef <发布提交> -NotesPath docs\current\release-notes-v1.0.6.md -ReleaseDate <发布日期>`。
6. `scripts/update-service/Publish-UpdateRelease.ps1 -ReleaseDirectory outputs\update-release-v1.0.6`，
   由脚本创建并推送 `v1.0.6` tag、上传资产、回验后设为 latest。
