## 精简内容

最终 `outputs/` 只保留一个可直接转发的安装 EXE。EXE 只携带 AutoCAD Bundle 必需的
`PackageContents.xml` 和 R23.1 `StructuralToolbox.dll`；构建 inventory、兼容矩阵、
安装说明、验证日志、哈希和回执保留在 `work/`，不重复嵌入安装包。

安装向导取消欢迎页、签名分类警告页、Ready 摘要页和开始菜单文档入口，只保留宿主
兼容性页以及 Inno Setup 必需的安装进度和完成页。

## 保留的安全控制

- AutoCAD、Core Console 和探索者进程关闭检查；
- AutoCAD 2020 R23.1 注册表、`acad.exe` 和 `acdbmgd.dll` 一致性检查；
- 当前用户/所有用户安装范围冲突检查；
- ProductCode、UpgradeCode 所有权检查；
- 升级、普通降级阻止、安装前备份和失败恢复；
- 卸载前宿主关闭检查，且只删除本产品 Bundle；
- 不修改 `SECURELOAD`、`TRUSTEDPATHS` 和用户工具设置。

签名元数据没有隐藏或伪造：发布定义、构建结果和产物验证仍要求并记录
`Authenticode=NotSigned`。
