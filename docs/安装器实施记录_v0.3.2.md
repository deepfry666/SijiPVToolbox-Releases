- 直接基线：已冻结的 `v0.3.1 TEST_UNSIGNED`
- 记录日期：2026-08-26

## 实施目标

`v0.3.2`延续 Inno Setup 6 单文件 EXE 安装方案，重点补齐安装前判断和用户提示，
同时保持已有安装、升级、回滚和卸载边界不变：

1. CAD 身份判断同时核对注册表 Series、Release、`acad.exe`固定 FileVersion、
   ProductVersion和`acdbmgd.dll`版本。
2. 兼容性页对每个检测到的宿主明确显示“可以安装”或“当前不支持”。
3. 准备安装页区分全新安装和升级，并显示既有版本到`0.3.2.0`的升级关系。
4. 完成页明确提示先启动或重启 AutoCAD，再输入`JJJJ`。
5. 保持稳定产品身份，确保`v0.2.0 -> v0.3.2`仍走同一产品升级链。

## AutoCAD 身份与支持状态

安装器从 64 位 HKLM/HKCU Autodesk 注册表枚举 AutoCAD。每个宿主同时检查：

- 注册表 Series；
- 注册表 Release；
- 注册安装目录和`acad.exe`是否存在；
- `acad.exe`固定 FileVersion或 ProductVersion是否与 Series 相符，并同时显示两项；
- `acdbmgd.dll`是否存在且文件版本是否与 Series 相符；
- 当前 release manifest 是否包含该 Series 的已验证 payload。

任一身份信息缺失或互相矛盾时，该宿主显示“【结论：当前不支持】”，且不会参与安装
资格判断。只有所有身份检查通过并且 Series 位于已验证清单时，才显示
“【结论：可以安装】”。当前唯一可显示“可以安装”的目标是 AutoCAD 2020 Win64
Series `R23.1`；2018-2019、2021-2026仍为候选，候选不等于兼容。

这项判断只决定安装包是否具有对应 payload，不把 GUI、Ribbon、探索者或系统级升级
状态并入“核心运行已验证”。这些外部验收继续单独记录。

## 安装向导信息

`scripts/installer/SijiPVToolbox.iss`负责以下可见信息：

- 欢迎页之后首先显示`TEST_UNSIGNED 未签名测试版`警告。
- 兼容性页逐项显示宿主身份数据、支持说明以及明确的安装结论。
- 若没有任何“可以安装”的宿主，正式/本机验收安装停止；隔离测试只可通过专用参数
  绕过，不能成为公开入口。
- 准备安装页显示版本、安装范围、插件目录和安装关系。检测到本产品旧版时显示
  “升级关系：<最高受管版本> -> 0.3.2.0”；没有旧版时显示
  “安装类型：全新安装（未检测到已安装的受管版本）”。
- 完成页提示“请先启动或重启 AutoCAD，再在命令行输入 JJJJ 打开四季光伏工具箱。”

## 安装、升级和卸载行为

- 当前用户安装目录：
  `%APPDATA%\Autodesk\ApplicationPlugins\ZhStructureToolbox.bundle`
- 全用户安装目录：
  `%ProgramFiles%\Autodesk\ApplicationPlugins\ZhStructureToolbox.bundle`
- 默认当前用户安装；已有系统级旧版时必须选择全用户安装并同意 UAC。
- 同时存在用户级和系统级安装时停止，避免 AutoCAD 重复加载。
- `acad.exe`或`accoreconsole.exe`运行时禁止安装、升级和卸载；安装器不会强制结束
  进程，也不会代替用户保存图纸。
- 升级前将旧 bundle 原子改名备份；失败恢复，成功后才清理备份。
- 普通降级被禁止；维护降级参数不出现在普通用户入口。
- 升级和卸载默认保留`%APPDATA%\StructuralToolbox`中的用户设置。
- 安装器不修改`SECURELOAD`、`TRUSTEDPATHS`或 DWG 文件。

## 构建与验证入口

- 纯代码和源码门禁：`scripts/test.ps1`
- SDK 验证及 Release 构建：`scripts/build.ps1`
- 单 EXE 候选构建：`scripts/package-installer.ps1`
- 安装器静态检查：`scripts/installer/Test-InstallerArtifacts.ps1`
- 隔离安装运行回归：`scripts/installer/Test-InstallerRuntime.ps1`
- AutoCAD 2020 CoreConsole：`scripts/verify-autocad2020.ps1`
- 最终发布证据：`scripts/New-ReleaseEvidence.ps1`

候选必须按“纯代码回归 -> fresh SDK 构建 -> 候选静态检查 -> 引用冻结候选 payload
的隔离安装回归 -> 同哈希 CoreConsole -> 发布证据”的顺序冻结。任何一个终态标记、
哈希绑定或签名分类不满足要求，都不得把候选写成已完成发布。

## 多版本与运行时边界

`bundle/manifest-template/compatibility-matrix.json`是兼容状态唯一清单。
AutoCAD 2018-2024规划为独立`.NET Framework`模块，2025及以后规划为独立
`.NET 8`模块；当前只构建和发布`acad2020-netfx / R23.1`。候选 Series 不进入
release manifest，也不会复用 R23.1 DLL 强行加载。

## 签名与更新边界

当前`allowedSignerThumbprints`为空，`publicDistributionAllowed=false`。因此本版只能
生成文件名、文件属性和安装界面均明确标记的`TEST_UNSIGNED`包，源 DLL、staged DLL
和 EXE 必须均为 Authenticode `NotSigned`。正式公开发布必须配置可信代码签名，对
全部 DLL、安装 EXE 和卸载器使用允许列表内的同一证书并加入可信时间戳，然后在干净
电脑重新验证。

`v0.3.2`没有在线更新服务、下载器或后台更新进程，只保留稳定 AppId/UpgradeCode、
完整 EXE 升级路径和签名校验边界。不得描述为“支持自动更新”。
