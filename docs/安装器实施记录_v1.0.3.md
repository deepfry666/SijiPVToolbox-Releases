# 四季光伏工具箱 v1.0.3 安装器实施记录

- 目标版本：`v1.0.3` / 程序集 `1.0.3.0`
- 交付目录：`SijiPVToolbox_v1.0.3_AutoCAD2020`
- 交付文件：`四季光伏工具箱_Setup_v1.0.3.exe`
- 发布分类：`UNSIGNED`
- Authenticode 预期：`NotSigned`

## 实施内容

- 配重生成继续使用一榀一个外层块，不改变既有移动、删除、冲突查看和重新生成流程。
- 配重统计进入榀块定义逐个校验标准圆墩或方墩，并按变换后的单墩中心判断框选范围。
- 模型空间中的标准单墩块直接计数；手画圆墩或闭合矩形经点选确认后写入可复制的单墩元数据。
- 旧版 `PZ_圆_...`、`PZ_方_...` 单墩以稳定块名恢复规格，并同时校验块内几何，外部参照不统计。
- 更新客户端按 VPS、GitHub 顺序尝试稳定清单，并支持清单内多个安装包地址回退。
- 五个正式程序集、Bundle、首页、About、README 和安装器统一为 `1.0.3.0`。

## 发布控制

稳定 ProductCode、UpgradeCode、安装范围标识和已接受的旧 ProductCode 沿用前版。
普通安装禁止降级；安装、升级和卸载仍要求 AutoCAD 已关闭。
