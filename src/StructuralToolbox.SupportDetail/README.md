# 混凝土屋面支架大样 v0.4.2

> 历史模块说明：当前 v1.0.8 正式工具箱不集成本模块。公开源码快照不包含工程 DWG 或固定详图库；下述嵌入资源、安装与历史运行描述不表示该资源已公开，也不表示本轮重新完成了 CAD 验收。需要独立构建和验证时，请先阅读根目录 `OPEN_SOURCE.md`，自备有权使用且结构符合预期的资源；没有资源时不能使用依赖详图库的功能。

以下说明保留 v0.4.2 时的模块设计。输入 `JJJJ` 打开当时的主工具箱，
从首页进入“混凝土屋面支架大样”。本版仍不读取自动画导轨或自动布置配重的结果。

## 文件

- `StructuralToolbox.SupportDetail.dll`：支架大样模块程序集，版本 `0.4.2.0`。
- 固定详图库已嵌入 DLL，首次使用节点详图时释放到当前用户的本地缓存。

历史版本安装器曾随主工具箱安装并加载本模块；当前正式安装包不包含本模块。

## 加载和命令

1. 执行 `JJJJ`，在首页打开“混凝土屋面支架大样”。
2. 点击“新建支架大样”，或执行 `STPVSUPPORTDETAIL`。
3. 点击“编辑选中实例”，选中任意一个工具生成的构件，
   回读参数并更新整个实例。

辅助命令：

- `STPVSUPPORTDETAILINFO`：读取所选实例的参数和关联实体数量。
- `STPVSUPPORTDETAILDELETE`：删除所选实例的全部工具实体和参数记录。
- `STPVSUPPORTDETAILCHECK`：在测试副本中生成、回读并更新诊断实例。
- `STPVSUPPORTDETAILREOPENCHECK`：重新打开诊断 DWG 后验证参数和原生实体。

## 参数基准

- `N`：单排剖面中的组件数量。
- `L`：组件斜长；`G`：相邻组件外轮廓净缝。
- `α`：支架倾角，支持任意小数角度。
- `r`：从每块组件低端沿斜面量至夹持/导轨中心线的位置；默认采用
  组件居中、两导轨中心距 `R=1400 mm`。
- `s`：从整个组件阵列低端沿斜面量至墩中心线的位置。
- `H`：第一个/最低基准墩位处，从支墩顶面到三角件底部的立柱高度；
  其余立柱高度按 `α` 和墩位自动求出，保证斜梁是一根直梁。
- `E`：斜梁端部至最外侧三角件中心线的距离，默认 `200 mm`。
- `D` 或 `Bx×By`：支墩外轮廓；`h`：支墩高度。

默认墩子数量采用 `P=N+1`，也可取消联动后输入数量，或直接输入全部
墩中心线位置。手动输入使用逗号、分号或空格分隔。

## 结果与边界

主支架由 AutoCAD 原生多段线、直线、圆、文字、尺寸和表格组成，
不是一个锁死的总块。每个实体保存稳定实例 ID，完整参数保存在 DWG
命名字典中，保存并重新打开后仍可回读更新。固定详图库从嵌入资源读取后作为单独块参照插入。

本版只完成几何和制图自动化，不进行杆件、节点、锚栓、混凝土支墩、
抗倾覆或承载力计算。任意墩位和立柱高度会保持直斜梁几何，但工程可行性仍需复核。

原始图纸中支墩尺寸存在两种表达：总体大样类似 `Φ500×400`，材料表为
`D500×300`。本版默认采用材料表的 `D500×300`，同时将直径和高度保留为
可编辑参数，不替代设计确认。
