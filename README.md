# 四季光伏工具箱下载

适用于 AutoCAD 2020 Win64。这里保存安装包、版本说明和 SHA-256 校验文件，源码仓库保持私有。

- [查看正式发行版](https://github.com/deepfry666/SijiPVToolbox-Releases/releases)
- [阿里云下载站](https://download.imfourj.cn/fourj-pv-toolbox/)

下载 Release 附件中的完整 `.exe` 安装包。安装前保存图纸，完全退出 AutoCAD 和探索者，再运行安装器。

当前归档为原有 v1.0.2 安装包；阿里云镜像尚待同步。现有客户端使用阿里云更新服务，多线路自动切换将在后续版本提供。

每个版本附带 `stable.json`、`sha256.txt` 和 `release.json`。相同版本的安装包内容固定；需要修复时发布新版本。`release.json` 中的源码提交标识用于维护者追溯，下载仓库的 Git 提交只记录公开说明。
